# TBNgoài — Thiết bị đơn vị ngoài lắp trên trụ chiếu sáng (CSKVTT)

PWA để cập nhật, cảnh báo và tổng hợp thống kê thiết bị của đơn vị ngoài (camera, viễn thông, quan trắc, đo điện, lễ hội, loa, biển báo, quảng cáo, tủ/hộp điện) gắn trên trụ chiếu sáng. Backend: Google Apps Script + Google Sheets.

- Thiết kế: `docs/TBNgoai-thiet-ke.md`
- Triển khai: `docs/TBNgoai-huong-dan-trien-khai.md`
- Code: `src/core.js` (lõi), `gas/Code.src.gs` → `dist/Code.gs`, `web/` (PWA)
- Test: `npm test` (66) · `node test/ui.e2e.mjs` (34)
